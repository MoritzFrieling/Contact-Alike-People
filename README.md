Branches:
- Main-branch:
  - Main app, final result of each sprint/final version of features
- Dev-branch:
  - Root-branch for developers. Every additional branch (new task) is a sub-branch of Developers. To submit a finished task, the developer opens a PR which has to be       approved by other developers. Afterwards, the sub-branch is merged into the developers-branch. To merge a feature from developers-branch to main-branch, the PO has       to accept the incoming changes of the developers-branch.


Definiton of Done:
- Code review Pull Request
- Accepted by PO

Information on Trello-Projectboard
- Main achievements/goals/features are defined within User Stories. These stories have been rated by applying the Planning Poker Game (Fibonacci)
- Rate which User Story consists of more effort compared to the other ones
- Each User Story is split up into smaller sub-tasks
- Each sub-task is related to specific topics (Front- or Backend, UX...)
- Each sub-task is rated with points that estimate the related time effort for each task
