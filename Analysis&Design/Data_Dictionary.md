## Analysis and Design

|  Words related to the user account  |      Definition     |
|----------|:-------------:|
| Login information |  refers to the email adress and the password for an account | 
| Personal information |  consists of the first and last name, the age, gender and a description as well as a picture | 
| Contact information | consists of at least one, but possibly multiple usernames on different platforms |
| Location information |  consists of street name, the house number, the city, the country as well as the postal Code | 
| Hobby selection |  When selecting a hobby, the actor needs to insert the skill level and the how long actor already does the hobby  | 

|  Words related to the Map  |      Definition     |
|----------|:-------------:|
| User overview |  Consists of the name, the picture, the biographie and the chosen hobbies | 
| Contact request |  a contact requests refers to a message towards another user to which the other user can reply with possible contact information | 
 Filter | filters users based on hobbies, range towards them(, possibly age and gender?) |
